# Nguồn tham khảo & giấy phép

Skill này được tinh lọc (chỉ phần dành cho Unity) và viết lại bằng tiếng Việt từ các bộ skill sau. Nội dung đã được
biên tập, gộp, và điều chỉnh theo quy ước làm việc của người dùng; hai script được sao chép nguyên văn có ghi nguồn ở đầu file.

| Nguồn | Giấy phép | Đã dùng |
|---|---|---|
| unity-coding-skills — Koji Hasegawa | Unlicense (public domain) | Quy trình test-first (plan-feature, fix-bug, refine-tests), thiết kế & viết test UTF, coding guideline theo phiên bản Unity, edit-scene qua editor script, uGUI defaults, YAML asset editing, `resolve_test_target.sh` (nguyên văn) |
| awesome-gamedev-agent-skills — Abhishek Barali & contributors | Apache-2.0 | Skill Unity (C# scripting, ScriptableObjects, build pipeline, input, physics, animation, NavMesh, Tilemap), disciplines (performance, save systems, level design, game feel, create-game-assets/art direction), `check_unity_project.py` (nguyên văn) |
| Claude Code Game Studios — Donchitos | MIT | Mô hình vai trò studio, chuẩn GDD 8 mục, art bible 9 mục, systems index, level doc, story/test evidence theo loại, thang bug S1–S4, Unity specialist agents, rigor modes, session checkpoint, run-and-observe screenshot |
| Unity-MCP-CLI (AI Game Developer) — Ivan Murzak | Apache-2.0 | Danh mục tool điều khiển Unity Editor qua MCP/CLI (tests-run, console-get-logs, script-execute, screenshot...) |
| superpowers — Jesse Vincent | MIT | Brainstorming → spec → plan, systematic debugging, verification-before-completion |
| ponytail — DietrichGebert | MIT | Nguyên tắc "thay đổi nhỏ nhất đủ yêu cầu", ghi chú `shortcut:` |
| SpriteCook skills, sprite-gen | MIT / Apache-2.0 | Chỉ tham khảo ý tưởng prompt card & quy trình duyệt asset mẫu (không dùng công cụ riêng của họ) |

Không dùng: các skill cho Godot, Unreal, Roblox, Bevy, Defold, LÖVE, pygame, Phaser, PixiJS, three.js, Ebitengine; các phần
phụ thuộc dịch vụ thương mại cụ thể.

Tên Unity, Rider và các sản phẩm khác là thương hiệu của chủ sở hữu tương ứng.
